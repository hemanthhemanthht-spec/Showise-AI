# ShopWise AI 🛒

### AI-Powered Smart Shopping Comparison Agent

ShopWise AI is an intelligent shopping comparison platform built using TinyFish. Users can enter a product name, upload a product image, or provide a product URL to find and compare products across major Indian e-commerce platforms.

## Features

- Product search using product names
- Product image-based search
- Product URL-based search
- Price comparison across e-commerce platforms
- Product specifications comparison
- Best-value product recommendations
- AI-powered web research using TinyFish

## Technology Stack

- Frontend: React
- Backend: Node.js
- AI Web Research: TinyFish
- API Integration: TinyFish API

## How It Works

1. User enters a product name, image, or URL.
2. ShopWise AI identifies the product.
3. TinyFish searches supported e-commerce websites.
4. The application collects available product information.
5. Products are compared based on price and specifications.
6. The system recommends the best-value option.
